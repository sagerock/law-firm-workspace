# Intake summary

1. Read the source material. Keep the original in `notes/`; never edit it.
2. Fill in or update `matter.md`: **Parties**, **Goals** (in the client's words where
   possible), **Key facts**, **Deadlines**.
3. Only record what the source says. If something is inferred, write `(inferred)`.
4. Below the summary, give the attorney:
   - **Missing information:** what's needed to advise or draft, as a checklist.
   - **Questions for the client:** plain-English, ready to send after review.
   - **Issues to consider:** concerns a careful attorney in this practice area would
     spot, each tied to the fact that raised it. Apply `firm/positions.md`. Mark
     anything that depends on current law `[verify]`.
5. Add the missing information as open items in `matter.md`.
6. Keep the summary scannable: headings and short bullets, no long paragraphs.
