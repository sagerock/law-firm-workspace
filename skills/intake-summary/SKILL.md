# Intake summary

1. Read the source material. Keep the original in `notes/`; never edit it.
2. Fill in or update `matter.md`: **Parties**, **Goals** (in the client's words where
   possible), **Key facts**, **Deadlines**.
3. Only record what the source says. If something is inferred, write `(inferred)`.
4. Write **Issues to consider** in `matter.md`: concerns a careful attorney in this
   practice area would spot, each tied to the fact that raised it. Apply
   `firm/positions.md`. Mark anything that depends on current law `[verify]`. These
   go in the file, not just the chat, so the next session has them.
5. Add what's still needed to advise or draft as **Open items**, each with an owner
   (client or firm).
6. Tell the attorney, briefly: the top issues, how many open items, and offer to
   draft the client's to-do list as a letter with `skills/client-letter`.
7. Keep everything scannable: headings and short bullets, no long paragraphs.
