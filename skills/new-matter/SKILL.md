# New matter

1. Pick a folder name like `lastname-short-description` from what you were given.
   Only ask if the client's name is missing. Mention the name; the attorney can
   change it.
2. Check `matters/` for a folder with the same client name. If one exists, ask
   whether this is a new matter or a continuation. Don't read its contents.
3. Create the folder with `notes/` and `drafts/` subfolders, and copy
   `matters/_template/matter.md` into it.
4. If intake notes were provided, save them unchanged in `notes/` as
   `YYYY-MM-DD intake notes.md`, then follow `skills/intake-summary` to fill in
   `matter.md`.
5. Set **Opened** to today, **Status** to `intake`, and **Responsible attorney** from
   `firm/profile.md` unless told otherwise.
6. List every person and organization named. Say: "Please run these names through your
   conflicts check before we go further." You are not the conflicts check.
7. Add open items for the conflicts check and the engagement letter. If more than one
   person is being represented (for example, spouses), note that the engagement
   letter should address joint representation.
8. Write **Where we left off** and tell the attorney what you created.
