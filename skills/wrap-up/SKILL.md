# Wrap up

1. In the matter's `matter.md`:
   - Replace **Where we left off** with today's date and two to four lines: what was
     done, what's next, and anything waiting on someone.
   - Check off finished **Open items** and add new ones with an owner.
   - Add any new **Deadlines** and **Decisions made** (dated, with who decided).
   - Update **Status** if it changed.
   - Make sure **Issues to consider** exists and reflects anything new.
   - Anyone added to **Parties** this session has a conflicts-check open item.
   - Each draft from this session has an open item saying who reviews and sends it.
     When the attorney says it went out, check it off and note the date.
2. Make sure every draft from this session is saved in `drafts/`.
3. Did the attorney correct you this session and agree to have it remembered? If so,
   add it to `firm/lessons.md` in general terms, with no client details.
4. Did a task come up that will repeat? Suggest `skills/make-a-skill`.
5. Tell the attorney in three lines or fewer what you saved.
