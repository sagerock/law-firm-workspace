# Skills

A skill is a written routine for a recurring task. When a request matches one, open its
`SKILL.md` and follow it. Each file uses the same format as Anthropic's Agent Skills, so
they can also be loaded as skills in apps that support them.

| Skill | Use when the person says something like |
|---|---|
| `start-of-day` | "Start my day," "What's on my plate?" |
| `new-matter` | "New matter," "Open a file for…," pastes intake notes for a new client |
| `intake-summary` | "Summarize this intake," "What do we know so far?" |
| `client-letter` | "Draft a letter/email to the client…" |
| `draft-review` | "Review this draft," "Check this against our positions" |
| `trust-funding-checklist` | "Funding steps," "What needs to be retitled?" |
| `wrap-up` | "Wrap up," "That's it for today," or the session is ending |
| `make-a-skill` | "Make this a skill," or the same task has come up a few times |

## Adding your own

Say "make this a skill" after doing a task you'll repeat, or follow `make-a-skill`.
Add a row to this table for every new skill. Put skills you don't use in `_unused/`.
