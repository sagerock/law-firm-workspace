# Matters

One folder per client matter. To start one, say "New matter" and the AI will copy
`_template/` for you (see `skills/new-matter`).

Folder names: `client-last-name-short-description`, for example `hartwell-trust`.

Each matter folder holds:

- `matter.md` — parties, status, deadlines, open items, and **Where we left off**.
- `notes/` — meeting notes, intake notes, call summaries.
- `drafts/` — AI and attorney drafts, date-prefixed, never overwritten.

`_example-hartwell-trust/` is fictional sample content to show how a matter looks in use.
